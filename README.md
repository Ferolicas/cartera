# Cartera

Panel privado para organizar ingresos, gastos y vencimientos, con balance proyectado y filtros temporales.

## Desarrollo

1. Copia `.env.example` a `.env` y completa las variables privadas.
2. Ejecuta `pnpm install`.
3. Aplica `pnpm db:migrate`.
4. Inicia con `pnpm dev`.

Validación completa: `pnpm check`.
